# Photographer Portfolio (React + Vite + Tailwind + Framer Motion)

1. `npm install` then `npm run dev`
2. Edit **src/data.js**: name, bio, stats, contact links and photo list.
3. Replace the placeholder images in **public/photos/** (keep names or update data.js). `profile.jpg` is the About photo.
4. Services text: src/components/Services.jsx. Accent colour: search `#ff2a2a` / `red-500`.
5. `npm run build` creates the `dist` folder to deploy on Netlify / Vercel / Render.
